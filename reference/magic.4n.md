# Magic squares of order 4n

Produces an associative magic square of order \\4n\\ using the delta-x
method.

## Usage

``` r
magic.4n(m)
```

## Arguments

- m:

  Order \\n\\ of the square is given by \\n=4m\\

## Author

Robin K. S. Hankin

## See also

[`magic`](https://robinhankin.github.io/magic/reference/magic.md)
