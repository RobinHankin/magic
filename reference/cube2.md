# A pantriagonal magic cube

A pantriagonal magic cube of order 4 originally due to Hendricks

## Usage

``` r
data(cube2)
```

## Details

Meaning of “pantriagonal” currently unclear

## Source

Hendricks

## Examples

``` r
data(cube2)
is.magichypercube(cube2)
#> [1] TRUE
is.perfect(cube2)
#> [1] FALSE
```
